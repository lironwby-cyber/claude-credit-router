# credit-router — סקיל ל-Claude שחוסך בקרדיטים בלי לפגוע באיכות

הסקיל מלמד את Claude לסווג כל משימה לפני שהוא מתחיל בה (A מכני / B מקצועי / C כבד / D קיצוני), ולבחור את המודל והסביבה הזולים ביותר שעדיין נותנים בדיוק אותה איכות. הוא גם מונע טעינה של חיבורים וכלים שלא נדרשים, קריאה של קבצים שלמים לתוך ההקשר וחזרה על עבודה שכבר נעשתה.

העיקרון: לחסוך רק בבזבוז. אם משימה צריכה מודל חזק כדי לצאת טוב, היא מקבלת אותו.

## התקנה ב-Claude (אתר / אפליקציה)

1. מורידים את הקובץ [`credit-router.zip`](credit-router.zip) מהמאגר הזה (לוחצים עליו ואז על כפתור ההורדה).
2. ב-Claude נכנסים ל-**Customize > Skills**.
3. לוחצים על **+**, אחר כך על **Create skill**, ובוחרים **Upload a skill**.
4. מעלים את קובץ ה-ZIP. אין צורך לפתוח אותו קודם.
5. מוודאים שהמתג ליד הסקיל דלוק.

צריך שב-Settings תהיה מופעלת האפשרות **Code execution and file creation**, אחרת סקילים לא עובדים.

## התקנה ב-Claude Code

מעתיקים את התיקייה `credit-router` לתוך `~/.claude/skills/`, כך שהקובץ יהיה בנתיב `~/.claude/skills/credit-router/SKILL.md`.

## טיפ להפעלה מלאה

כדי ש-Claude ישתמש בסקיל בכל שיחה, אפשר להוסיף שורה ב-**Settings > General > Instructions for Claude**, למשל:

> בתחילת כל שיחה ולפני כל משימה כבדה: סווג את המשימה (A מכני / B מקצועי / C כבד / D קיצוני), ובחר את המודל והסביבה הזולים ביותר שנותנים בדיוק אותה איכות. אל תטען חיבורים וכלים שאינם נדרשים למשימה. אם סבב זול נכשל, העלה רמה בלי לשאול. לעולם אל תקצר תוצר, אל תדלג על בדיקה ואל תוריד איכות כדי לחסוך קרדיטים.

## שימו לב

- שמות המודלים בטבלה (Haiku / Sonnet / Opus / Fable) נכונים לנובמבר 2026. כשיוצאים מודלים חדשים, מעדכנים את הטבלה ב-`SKILL.md`.
- כמה קרדיט נשאר אפשר לראות רק ב-**Settings > Usage**. הסקיל לא מנחש מספרים.
